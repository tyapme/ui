## shadcn/create を使う

<Steps>

### プリセットを作成する

[shadcn/create](/create?template=astro) を開き、プリセットをビジュアルで作成します。スタイル、カラー、フォント、アイコンなどを選択してください。

<Button asChild size="sm">
  <Link
    href="/create?template=astro"
    target="_blank"
    rel="noopener noreferrer"
    className="mt-6 no-underline!"
  >
    shadcn/create を開く
  </Link>
</Button>

### プロジェクトを作成する

`Create Project` をクリックし、パッケージマネージャーを選んで、生成されたコマンドをコピーします。

生成されるコマンドはこのようになります：

```bash
npx shadcn@latest init --preset [CODE] --template astro
```

`--base`、`--monorepo`、`--rtl` など選択したオプションが含まれます。

### コンポーネントを追加する

`Card` コンポーネントをプロジェクトに追加します：

```bash
npx shadcn@latest add card
```

モノレポを作成した場合は `apps/web` からコマンドを実行するか、リポジトリルートからワークスペースを指定します：

```bash
npx shadcn@latest add card -c apps/web
```

上のコマンドで `Card` コンポーネントが追加されます。次のようにインポートできます：

```astro title="src/pages/index.astro" showLineNumbers
---
import Layout from "@/layouts/main.astro"
import {
  Card,
  CardContent,
  CardDescription,
  CardHeader,
  CardTitle,
} from "@/components/ui/card"
---

<Layout>
  <Card className="max-w-sm">
    <CardHeader>
      <CardTitle>Project Overview</CardTitle>
      <CardDescription>
        Track progress and recent activity for your Astro app.
      </CardDescription>
    </CardHeader>
    <CardContent>
      Your design system is ready. Start building your next component.
    </CardContent>
  </Card>
</Layout>
```

モノレポを作成した場合は `apps/web/src/pages/index.astro` を更新し、`@workspace/ui/components/card` からインポートしてください。モノレポのレイアウト `apps/web/src/layouts/main.astro` はすでに `@workspace/ui/globals.css` をインポートしています。

</Steps>

## CLI を使う

<Steps>

### プロジェクトを作成する

`init` コマンドで新しい Astro プロジェクトをスキャフォールドします。プロンプトに従って、ベース、プリセット、モノレポなどを設定してください。

```bash
npx shadcn@latest init -t astro
```

**モノレポの場合は `--monorepo` フラグを使用します：**

```bash
npx shadcn@latest init -t astro --monorepo
```

### コンポーネントを追加する

## 既存プロジェクト

<Steps>

### プロジェクトを作成する

新しい Astro プロジェクトが必要な場合はまず作成します。不要な場合はこのステップをスキップしてください。

```bash
npm create astro@latest astro-app -- --template with-tailwindcss --install --add react --git
```

このコマンドで Tailwind CSS と React インテグレーションがセットアップされます。古いまたはカスタムの Astro アプリに shadcn/ui を追加する場合は、両方が設定済みであることを確認してから続けてください。

Tailwind スターターはグローバルスタイルシートを `src/layouts/main.astro` から読み込みます。このレイアウトをそのままにするか、ページが `@/styles/global.css` をインポートするようにしてください。

### tsconfig.json ファイルを編集する

プロジェクトにすでに `@/*` エイリアスが設定されている場合はこのステップをスキップしてください。

パスを解決するために `tsconfig.json` に以下のコードを追加します：

```ts title="tsconfig.json" {4-9} showLineNumbers
{
  "compilerOptions": {
    // ...
    "baseUrl": ".",
    "paths": {
      "@/*": [
        "./src/*"
      ]
    }
    // ...
  }
}
```

### CLI を実行する

`shadcn` init コマンドでプロジェクトをセットアップします：

```bash
npx shadcn@latest init
```

### コンポーネントを追加する

これでプロジェクトにコンポーネントを追加できます。

```bash
npx shadcn@latest add button
```

上のコマンドで `Button` コンポーネントが追加されます。次のようにインポートできます：

```astro title="src/pages/index.astro" showLineNumbers
---
import Layout from "@/layouts/main.astro"
import { Button } from "@/components/ui/button"
---

<Layout>
  <div class="grid h-screen place-items-center content-center">
    <Button>Button</Button>
  </div>
</Layout>
```

</Steps>
