## shadcn/create を使う

<Steps>

### プリセットを作成する

[shadcn/create](/create?template=next) を開き、プリセットをビジュアルで作成します。スタイル、カラー、フォント、アイコンなどを選択してください。

<Button asChild size="sm">
  <Link
    href="/create?template=next"
    target="_blank"
    rel="noopener noreferrer"
    className="mt-6 no-underline!"
  >
    shadcn/create を開く
  </Link>
</Button>

### プロジェクトを作成する

`Create Project` をクリックし、パッケージマネージャーを選んで、生成されたコマンドをコピーします。

生成されるコマンドはこのようになります：

```bash
npx shadcn@latest init --preset [CODE] --template next
```

`--base`、`--monorepo`、`--rtl` など選択したオプションが含まれます。

### コンポーネントを追加する

`Card` コンポーネントをプロジェクトに追加します：

```bash
npx shadcn@latest add card
```

モノレポを作成した場合は `apps/web` からコマンドを実行するか、リポジトリルートからワークスペースを指定します：

```bash
npx shadcn@latest add card -c apps/web
```

上のコマンドで `Card` コンポーネントが追加されます。次のようにインポートできます：

```tsx showLineNumbers title="app/page.tsx"
import {
  Card,
  CardContent,
  CardDescription,
  CardHeader,
  CardTitle,
} from "@/components/ui/card"

export default function Home() {
  return (
    <Card className="max-w-sm">
      <CardHeader>
        <CardTitle>Project Overview</CardTitle>
        <CardDescription>
          Track progress and recent activity for your Next.js app.
        </CardDescription>
      </CardHeader>
      <CardContent>
        Your design system is ready. Start building your next component.
      </CardContent>
    </Card>
  )
}
```

モノレポを作成した場合は `apps/web/app/page.tsx` を更新し、`@workspace/ui/components/card` からインポートしてください。

</Steps>

## CLI を使う

<Steps>

### プロジェクトを作成する

`init` コマンドで新しい Next.js プロジェクトをスキャフォールドします。プロンプトに従って、ベース、プリセット、モノレポなどを設定してください。

```bash
npx shadcn@latest init -t next
```

**モノレポの場合は `--monorepo` フラグを使用します：**

```bash
npx shadcn@latest init -t next --monorepo
```

### コンポーネントを追加する

```bash
npx shadcn@latest add card
```

モノレポを作成した場合は `apps/web` からコマンドを実行するか、リポジトリルートからワークスペースを指定します：


## 既存プロジェクト

<Steps>

### プロジェクトを作成する

新しい Next.js プロジェクトが必要な場合は `create-next-app` で作成します。不要な場合はこのステップをスキップしてください。

```bash
npx create-next-app@latest
```

Tailwind CSS、App Router、デフォルトの `@/*` インポートエイリアスが設定されるよう、推奨デフォルトを選択してください。

`src/` ディレクトリを使う場合は `--src-dir` オプションを使うか、プロンプトで `Yes` を選択してください：

```bash
npx create-next-app@latest --src-dir
```

`--src-dir` を使うと、Next.js はアプリを `src/app` に配置し、`@/*` エイリアスを `./src/*` に設定します。

### Tailwind CSS とインポートエイリアスを設定する

推奨デフォルトで `create-next-app` を作成した場合はこのステップをスキップできます。

古いまたはカスタムの Next.js アプリに shadcn/ui を追加する場合は、まず Tailwind CSS がインストールされていることを確認してください。公式の [Next.js インストールガイド](https://nextjs.org/docs/app/getting-started) を参照してください。

次に `tsconfig.json` に `@/*` インポートエイリアスが含まれていることを確認します：

```json title="tsconfig.json" showLineNumbers
{
  "compilerOptions": {
    "paths": {
      "@/*": ["./*"]
    }
  }
}
```

`--src-dir` を使った場合は、エイリアスを `./src/*` に設定してください。

### CLI を実行する

`shadcn` init コマンドでプロジェクトをセットアップします：

```bash
npx shadcn@latest init
```

### コンポーネントを追加する

これでプロジェクトにコンポーネントを追加できます。

```bash
npx shadcn@latest add button
```

上のコマンドで `Button` コンポーネントが追加されます。次のようにインポートできます：

```tsx showLineNumbers title="app/page.tsx"
import { Button } from "@/components/ui/button"

export default function Home() {
  return (
    <div className="flex min-h-svh items-center justify-center">
      <Button>Click me</Button>
    </div>
  )
}
```

`--src-dir` を使った場合は `src/app/page.tsx` にコンポーネントを追加してください。

</Steps>
