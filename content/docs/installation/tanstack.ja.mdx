## shadcn/create を使う

<Steps>

### プリセットを作成する

[shadcn/create](/create?template=start) を開き、プリセットをビジュアルで作成します。スタイル、カラー、フォント、アイコンなどを選択してください。

<Button asChild size="sm">
  <Link
    href="/create?template=start"
    target="_blank"
    rel="noopener noreferrer"
    className="mt-6 no-underline!"
  >
    shadcn/create を開く
  </Link>
</Button>

### プロジェクトを作成する

`Create Project` をクリックし、パッケージマネージャーを選んで、生成されたコマンドをコピーします。

生成されるコマンドはこのようになります：

```bash
npx shadcn@latest init --preset [CODE] --template start
```

`--base`、`--monorepo`、`--rtl` など選択したオプションが含まれます。

### コンポーネントを追加する

`Card` コンポーネントをプロジェクトに追加します：

```bash
npx shadcn@latest add card
```

モノレポを作成した場合は `apps/web` からコマンドを実行するか、リポジトリルートからワークスペースを指定します：

```bash
npx shadcn@latest add card -c apps/web
```

上のコマンドで `Card` コンポーネントが追加されます。次のようにインポートできます：

```tsx showLineNumbers title="src/routes/index.tsx"
import { createFileRoute } from "@tanstack/react-router"

import {
  Card,
  CardContent,
  CardDescription,
  CardHeader,
  CardTitle,
} from "@/components/ui/card"

export const Route = createFileRoute("/")({
  component: App,
})

function App() {
  return (
    <Card className="max-w-sm">
      <CardHeader>
        <CardTitle>Project Overview</CardTitle>
        <CardDescription>
          Track progress and recent activity for your TanStack Start app.
        </CardDescription>
      </CardHeader>
      <CardContent>
        Your design system is ready. Start building your next component.
      </CardContent>
    </Card>
  )
}
```

モノレポを作成した場合は `apps/web/src/routes/index.tsx` を更新し、`@workspace/ui/components/card` からインポートしてください。

</Steps>

## CLI を使う

<Steps>

### プロジェクトを作成する

`init` コマンドで新しい TanStack Start プロジェクトをスキャフォールドします。プロンプトに従って、ベース、プリセット、モノレポなどを設定してください。

```bash
npx shadcn@latest init -t start
```

**モノレポの場合は `--monorepo` フラグを使用します：**

```bash
npx shadcn@latest init -t start --monorepo
```

### コンポーネントを追加する

`Card` コンポーネントをプロジェクトに追加します：

```bash
npx shadcn@latest add card
```

モノレポを作成した場合は `apps/web` からコマンドを実行するか、リポジトリルートからワークスペースを指定します：

```bash
npx shadcn@latest add card -c apps/web
```

## 既存プロジェクト

<Steps>

### プロジェクトを作成する

新しい TanStack Start プロジェクトが必要な場合はまず作成します。不要な場合はこのステップをスキップしてください。

```bash
npx @tanstack/cli@latest create
```

TanStack Start、React フレームワーク、推奨デフォルトを選択し、Tailwind CSS と `@/*` インポートエイリアスが自動で設定されるようにしてください。

<Callout className="mt-6">

プロンプトで `shadcn` アドオンは追加しないでください。`shadcn` CLI がこのガイドの後半で shadcn/ui を設定します。

</Callout>

TanStack CLI は Tailwind CSS とデフォルトの `@/*` インポートエイリアスを自動で設定します。古いまたはカスタムの TanStack Start アプリに shadcn/ui を追加する場合は、両方が設定済みであることを確認してから続けてください。

### CLI を実行する

`shadcn` init コマンドでプロジェクトをセットアップします：

```bash
npx shadcn@latest init
```

### コンポーネントを追加する

これでプロジェクトにコンポーネントを追加できます。

```bash
npx shadcn@latest add button
```

上のコマンドで `Button` コンポーネントが追加されます。次のようにインポートできます：

```tsx showLineNumbers title="src/routes/index.tsx"
import { createFileRoute } from "@tanstack/react-router"

import { Button } from "@/components/ui/button"

export const Route = createFileRoute("/")({
  component: App,
})

function App() {
  return (
    <div className="flex min-h-svh items-center justify-center p-6">
      <Button>Click me</Button>
    </div>
  )
}
```

</Steps>
