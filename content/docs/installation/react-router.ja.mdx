## shadcn/create を使う

<Steps>

### プリセットを作成する

[shadcn/create](/create?template=react-router) を開き、プリセットをビジュアルで作成します。スタイル、カラー、フォント、アイコンなどを選択してください。

<Button asChild size="sm">
  <Link
    href="/create?template=react-router"
    target="_blank"
    rel="noopener noreferrer"
    className="mt-6 no-underline!"
  >
    shadcn/create を開く
  </Link>
</Button>

### プロジェクトを作成する

`Create Project` をクリックし、パッケージマネージャーを選んで、生成されたコマンドをコピーします。

生成されるコマンドはこのようになります：

```bash
npx shadcn@latest init --preset [CODE] --template react-router
```

`--base`、`--monorepo`、`--rtl` など選択したオプションが含まれます。

### コンポーネントを追加する

`Card` コンポーネントをプロジェクトに追加します：

```bash
npx shadcn@latest add card
```

モノレポを作成した場合は `apps/web` からコマンドを実行するか、リポジトリルートからワークスペースを指定します：

```bash
npx shadcn@latest add card -c apps/web
```

上のコマンドで `Card` コンポーネントが追加されます。次のようにインポートできます：

```tsx showLineNumbers title="app/routes/home.tsx"
import {
  Card,
  CardContent,
  CardDescription,
  CardHeader,
  CardTitle,
} from "~/components/ui/card"

export default function Home() {
  return (
    <Card className="max-w-sm">
      <CardHeader>
        <CardTitle>Project Overview</CardTitle>
        <CardDescription>
          Track progress and recent activity for your React Router app.
        </CardDescription>
      </CardHeader>
      <CardContent>
        Your design system is ready. Start building your next component.
      </CardContent>
    </Card>
  )
}
```

モノレポを作成した場合は `apps/web/app/routes/home.tsx` を更新し、`@workspace/ui/components/card` からインポートしてください。

</Steps>

## CLI を使う

<Steps>

### プロジェクトを作成する

`init` コマンドで新しい React Router プロジェクトをスキャフォールドします。プロンプトに従って、ベース、プリセット、モノレポなどを設定してください。

```bash
npx shadcn@latest init -t react-router
```

**モノレポの場合は `--monorepo` フラグを使用します：**

```bash
npx shadcn@latest init -t react-router --monorepo
```

### コンポーネントを追加する

## 既存プロジェクト

<Steps>

### プロジェクトを作成する

新しい React Router プロジェクトが必要な場合はまず作成します。不要な場合はこのステップをスキップしてください。

```bash
npm create react-router@latest
```

`create-react-router` は Tailwind CSS とデフォルトの `~/*` インポートエイリアスを自動で設定します。古いまたはカスタムの React Router アプリに shadcn/ui を追加する場合は、両方が設定済みであることを確認してから続けてください。

### CLI を実行する

`shadcn` init コマンドでプロジェクトをセットアップします：

```bash
npx shadcn@latest init
```

### コンポーネントを追加する

これでプロジェクトにコンポーネントを追加できます。

```bash
npx shadcn@latest add button
```

上のコマンドで `Button` コンポーネントが追加されます。次のようにインポートできます：

```tsx showLineNumbers title="app/routes/home.tsx"
import { Button } from "~/components/ui/button"

export default function Home() {
  return (
    <div className="flex min-h-svh flex-col items-center justify-center">
      <Button>Click me</Button>
    </div>
  )
}
```

</Steps>
