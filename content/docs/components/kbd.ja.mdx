<ComponentInstall name="kbd" styleName="base-nova" />

## 使い方

```tsx
import { Kbd } from "@/components/ui/kbd"
```

```tsx
<Kbd>Ctrl</Kbd>
```

## 構成

`Kbd` と `KbdGroup` を構築するには以下の構成を使用します:

```text
Kbd
KbdGroup
├── Kbd
└── Kbd
```

## API リファレンス

### Kbd

キーボードキーを表示するために `Kbd` コンポーネントを使用します。

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` | ``      |

```tsx
<Kbd>Ctrl</Kbd>
```

### KbdGroup

`Kbd` コンポーネントをグループ化するために `KbdGroup` コンポーネントを使用します。

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` | ``      |

```tsx
<KbdGroup>
  <Kbd>Ctrl</Kbd>
  <Kbd>B</Kbd>
</KbdGroup>
```
