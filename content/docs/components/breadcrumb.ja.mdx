## 使い方

```tsx showLineNumbers
import {
  Breadcrumb,
  BreadcrumbItem,
  BreadcrumbLink,
  BreadcrumbList,
  BreadcrumbPage,
  BreadcrumbSeparator,
} from "@/components/ui/breadcrumb"
```

```tsx showLineNumbers
<Breadcrumb>
  <BreadcrumbList>
    <BreadcrumbItem>
      <BreadcrumbLink render={<a href="/" />}>Home</BreadcrumbLink>
    </BreadcrumbItem>
    <BreadcrumbSeparator />
    <BreadcrumbItem>
      <BreadcrumbLink render={<a href="/components" />}>
        Components
      </BreadcrumbLink>
    </BreadcrumbItem>
    <BreadcrumbSeparator />
    <BreadcrumbItem>
      <BreadcrumbPage>Breadcrumb</BreadcrumbPage>
    </BreadcrumbItem>
  </BreadcrumbList>
</Breadcrumb>
```

## 構成

`Breadcrumb` の構成:

```text
Breadcrumb
└── BreadcrumbList
    ├── BreadcrumbItem
    │   └── BreadcrumbLink
    ├── BreadcrumbSeparator
    ├── BreadcrumbItem
    │   └── BreadcrumbLink
    ├── BreadcrumbSeparator
    └── BreadcrumbItem
        └── BreadcrumbPage
```

## API リファレンス

### Breadcrumb

`Breadcrumb` コンポーネントはすべてのパンくずコンポーネントをラップするルートナビゲーション要素です。

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` | -       |

### BreadcrumbList

`BreadcrumbList` コンポーネントはパンくずアイテムの順序付きリストを表示します。

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` | -       |

### BreadcrumbItem

`BreadcrumbItem` コンポーネントは個々のパンくずアイテムをラップします。

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` | -       |

### BreadcrumbLink

`BreadcrumbLink` コンポーネントはパンくずリスト内のクリック可能なリンクを表示します。

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` | -       |

### BreadcrumbPage

`BreadcrumbPage` コンポーネントはパンくずリスト内の現在のページ（クリック不可）を表示します。

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` | -       |

### BreadcrumbSeparator

`BreadcrumbSeparator` コンポーネントはパンくずアイテム間のセパレーターを表示します。カスタムの子要素を渡してデフォルトのセパレーターアイコンを上書きできます。

| Prop        | Type              | Default |
| ----------- | ----------------- | ------- |
| `children`  | `React.ReactNode` | -       |
| `className` | `string`          | -       |

### BreadcrumbEllipsis

`BreadcrumbEllipsis` コンポーネントは折りたたまれたパンくずアイテムの省略記号インジケーターを表示します。

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` | -       |
