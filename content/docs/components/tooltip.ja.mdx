## 使い方

```tsx showLineNumbers
import {
  Tooltip,
  TooltipContent,
  TooltipTrigger,
} from "@/components/ui/tooltip"
```

```tsx showLineNumbers
<Tooltip>
  <TooltipTrigger>Hover</TooltipTrigger>
  <TooltipContent>
    <p>Add to library</p>
  </TooltipContent>
</Tooltip>
```

## コンポジション

`Tooltip` を構築するには以下のコンポジションを使用します:

```text
Tooltip
├── TooltipTrigger
└── TooltipContent
```
