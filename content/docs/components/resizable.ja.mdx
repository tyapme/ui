## 概要

`Resizable` コンポーネントは [bvaughn](https://github.com/bvaughn) による [react-resizable-panels](https://github.com/bvaughn/react-resizable-panels) の上に構築されています。

## インストール

<ComponentInstall name="resizable" styleName="base-nova" />

## 使い方

```tsx showLineNumbers
import {
  ResizableHandle,
  ResizablePanel,
  ResizablePanelGroup,
} from "@/components/ui/resizable"
```

```tsx showLineNumbers
<ResizablePanelGroup orientation="horizontal">
  <ResizablePanel>One</ResizablePanel>
  <ResizableHandle />
  <ResizablePanel>Two</ResizablePanel>
</ResizablePanelGroup>
```

## コンポジション

`ResizablePanelGroup` を構築するには以下のコンポジションを使用します:

```text
ResizablePanelGroup
├── ResizablePanel
├── ResizableHandle
└── ResizablePanel
```

## 変更履歴

### 2025-02-02 `react-resizable-panels` v4

`react-resizable-panels` v4 に更新しました。詳細は [v4.0.0 リリースノート](https://github.com/bvaughn/react-resizable-panels/releases/tag/4.0.0)を参照してください。

`react-resizable-panels` のプリミティブを直接使用している場合は、以下の変更点に注意してください:

| v3                           | v4                      |
| ---------------------------- | ----------------------- |
| `PanelGroup`                 | `Group`                 |
| `PanelResizeHandle`          | `Separator`             |
| `direction` prop             | `orientation` prop      |
| `defaultSize={50}`           | `defaultSize="50%"`     |
| `onLayout`                   | `onLayoutChange`        |
| `ImperativePanelHandle`      | `PanelImperativeHandle` |
| `ref` prop on Panel          | `panelRef` prop         |
| `data-panel-group-direction` | `aria-orientation`      |

<Callout>
  shadcn/ui のラッパーコンポーネント（`ResizablePanelGroup`、`ResizablePanel`、`ResizableHandle`）は変更ありません。
</Callout>
