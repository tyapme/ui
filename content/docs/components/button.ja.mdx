
```tsx
<Button variant="outline">Button</Button>
```

## カーソル

Tailwind v4 では、ボタンコンポーネントのカーソルが `cursor: pointer` から `cursor: default` に[変更](https://tailwindcss.com/docs/upgrade-guide#buttons-use-the-default-cursor)されました。

`cursor: pointer` の挙動を維持したい場合は、CSS ファイルに以下のコードを追加してください：

`npx shadcn@latest init --pointer` で初期化時に有効にすることもできます。

```css showLineNumbers title="globals.css"
@layer base {
  button:not(:disabled),
  [role="button"]:not(:disabled) {
    cursor: pointer;
  }
}
```

### リンクとして使う

`buttonVariants` ヘルパーを使うと、リンクをボタンのように見せることができます。

**リンクには `<Button render={<a />} nativeButton={false} />` を使用しないでください。** Base UI の `Button` コンポーネントは常に `role="button"` を適用するため、`<a>` 要素のセマンティックなリンクロールが上書きされます。代わりに `buttonVariants` をプレーンな `<a>` タグとともに使用してください。

## API リファレンス

### Button

`Button` コンポーネントは、さまざまなスタイルと機能を追加した `button` 要素のラッパーです。

| プロップ   | 型                                                                                    | デフォルト  |
| --------- | ------------------------------------------------------------------------------------- | ----------- |
| `variant` | `"default" \| "outline" \| "ghost" \| "destructive" \| "secondary" \| "link"`        | `"default"` |
| `size`    | `"default" \| "xs" \| "sm" \| "lg" \| "icon" \| "icon-xs" \| "icon-sm" \| "icon-lg"` | `"default"` |
