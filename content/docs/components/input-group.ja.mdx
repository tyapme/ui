## 使い方

```tsx showLineNumbers
import {
  InputGroup,
  InputGroupAddon,
  InputGroupButton,
  InputGroupInput,
  InputGroupText,
  InputGroupTextarea,
} from "@/components/ui/input-group"
```

```tsx showLineNumbers
<InputGroup>
  <InputGroupInput placeholder="Search..." />
  <InputGroupAddon>
    <SearchIcon />
  </InputGroupAddon>
</InputGroup>
```

## 構成

`InputGroup` を構築するには以下の構成を使用します:

```text
InputGroup
├── InputGroupInput or InputGroupTextarea
├── InputGroupAddon
├── InputGroupButton
└── InputGroupText
```

## 配置（Align）

`InputGroupAddon` の `align` プロパティを使用して、入力に対するアドオンの位置を設定します。

<Callout>
  適切なフォーカス管理のために、`InputGroupAddon` は DOM 上で常に
  `InputGroupInput` または `InputGroupTextarea` の後に配置してください。`align` プロパティで視覚的な位置を設定します。
</Callout>

### inline-start

`align="inline-start"` を使用してアドオンを入力の先頭に配置します。これがデフォルトです。

## API リファレンス

### InputGroup

入力とアドオンをラップするメインコンポーネント。

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` |         |

```tsx
<InputGroup>
  <InputGroupInput />
  <InputGroupAddon />
</InputGroup>
```

### InputGroupAddon

入力と並んでアイコン、テキスト、ボタンなどのコンテンツを表示します。

<Callout icon={<IconInfoCircle />} title="フォーカスのナビゲーション">
  適切なフォーカスナビゲーションのために、`InputGroupAddon` コンポーネントは入力の後に配置してください。`align` プロパティでアドオンの位置を設定します。
</Callout>

| Prop        | Type                                                             | Default          |
| ----------- | ---------------------------------------------------------------- | ---------------- |
| `align`     | `"inline-start" \| "inline-end" \| "block-start" \| "block-end"` | `"inline-start"` |
| `className` | `string`                                                         |                  |

```tsx
<InputGroupAddon align="inline-end">
  <SearchIcon />
</InputGroupAddon>
```

**`<InputGroupInput />` には `inline-start` または `inline-end` の配置を、`<InputGroupTextarea />` には `block-start` または `block-end` の配置を使用してください。**

`InputGroupAddon` コンポーネントには複数の `InputGroupButton` コンポーネントとアイコンを含められます。

```tsx
<InputGroupAddon>
  <InputGroupButton>Button</InputGroupButton>
  <InputGroupButton>Button</InputGroupButton>
</InputGroupAddon>
```

### InputGroupButton

入力グループ内にボタンを表示します。

| Prop        | Type                                                                          | Default   |
| ----------- | ----------------------------------------------------------------------------- | --------- |
| `size`      | `"xs" \| "icon-xs" \| "sm" \| "icon-sm"`                                      | `"xs"`    |
| `variant`   | `"default" \| "destructive" \| "outline" \| "secondary" \| "ghost" \| "link"` | `"ghost"` |
| `className` | `string`                                                                      |           |

```tsx
<InputGroupButton>Button</InputGroupButton>
<InputGroupButton size="icon-xs" aria-label="Copy">
  <CopyIcon />
</InputGroupButton>
```

### InputGroupInput

入力グループを構築する際の `<Input />` の代替コンポーネント。入力グループのスタイルが事前に適用されており、フォーカス状態の処理に統一された `data-slot="input-group-control"` を使用します。

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` |         |

その他のすべてのプロパティは基盤となる `<Input />` コンポーネントに渡されます。

```tsx
<InputGroup>
  <InputGroupInput placeholder="Enter text..." />
  <InputGroupAddon>
    <SearchIcon />
  </InputGroupAddon>
</InputGroup>
```

### InputGroupTextarea

入力グループを構築する際の `<Textarea />` の代替コンポーネント。テキストエリアグループのスタイルが事前に適用されており、フォーカス状態の処理に統一された `data-slot="input-group-control"` を使用します。

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` |         |

その他のすべてのプロパティは基盤となる `<Textarea />` コンポーネントに渡されます。

```tsx
<InputGroup>
  <InputGroupTextarea placeholder="Enter message..." />
  <InputGroupAddon align="block-end">
    <InputGroupButton>Send</InputGroupButton>
  </InputGroupAddon>
</InputGroup>
```
