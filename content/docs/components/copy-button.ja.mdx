## API リファレンス

### CopyButton

| プロパティ    | 型                              | デフォルト  |

| `size`      | `"sm" \| "default" \| "lg"`      | `"default"` |
| `variant`   | `ButtonProps["variant"]`          | `"ghost"`   |
| `timeout`   | `number`                          | `1800`      |
| `onCopy`    | `(value: string) => void`         | —           |
| `className` | `string`                          | —           |
