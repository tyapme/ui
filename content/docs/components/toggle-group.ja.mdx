## 使い方

```tsx
import { ToggleGroup, ToggleGroupItem } from "@/components/ui/toggle-group"
```

```tsx
<ToggleGroup type="single">
  <ToggleGroupItem value="a">A</ToggleGroupItem>
  <ToggleGroupItem value="b">B</ToggleGroupItem>
  <ToggleGroupItem value="c">C</ToggleGroupItem>
</ToggleGroup>
```

## コンポジション

`ToggleGroup` を構築するには以下のコンポジションを使用します:

```text
ToggleGroup
├── ToggleGroupItem
└── ToggleGroupItem
```

## 変更履歴

### 2026-05-17 デフォルト間隔

デフォルトの `spacing` を `0` から `2` に変更し、トグルグループがデフォルトでアイテム間にスペースを持ってレンダリングされるようにしました。連結したアイテムには `spacing={0}` を使用します。
