## チェック状態

非制御のチェックボックスには `defaultChecked` を、状態を制御するには `checked` と `onCheckedChange` を使用します。

```tsx showLineNumbers
import * as React from "react"

export function Example() {
  const [checked, setChecked] = React.useState(false)

  return <Checkbox checked={checked} onCheckedChange={setChecked} />
}
```

## 無効状態

チェックボックスに `aria-invalid` を設定し、フィールドのラッパーに `data-invalid` を設定して無効スタイルを表示します。
