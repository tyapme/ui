サイドバーは構築が最も複雑なコンポーネントの一つです。あらゆるアプリケーションの中心であり、多くの動的なパーツを含むことが多いです。

堅固な基盤ができました。コンポーザブル。テーマ適用可能。カスタマイズ可能。

[ブロックライブラリを閲覧する](/blocks)。

<ComponentInstall name="sidebar" styleName="base-nova" />

## 使い方

```tsx showLineNumbers title="app/layout.tsx"
import { SidebarProvider, SidebarTrigger } from "@/components/ui/sidebar"
import { AppSidebar } from "@/components/app-sidebar"

export default function Layout({ children }: { children: React.ReactNode }) {
  return (
    <SidebarProvider>
      <AppSidebar />
      <main>
        <SidebarTrigger />
        {children}
      </main>
    </SidebarProvider>
  )
}
```

```tsx showLineNumbers title="components/app-sidebar.tsx"
import {
  Sidebar,
  SidebarContent,
  SidebarFooter,
  SidebarGroup,
  SidebarHeader,
} from "@/components/ui/sidebar"

export function AppSidebar() {
  return (
    <Sidebar>
      <SidebarHeader />
      <SidebarContent>
        <SidebarGroup />
        <SidebarGroup />
      </SidebarContent>
      <SidebarFooter />
    </Sidebar>
  )
}
```

## 構造

- **SidebarProvider** — 折りたたみ状態を処理し、子コンポーネントにサイドバーコンテキストを提供します。
- **Sidebar** — 折りたたみ可能なメインサイドバーパネル。
- **SidebarHeader** — 上部に固定。ブランディング、タイトル、ワークスペーススイッチャーに使用します。
- **SidebarFooter** — 下部に固定。ユーザーメニュー、設定、アクションに使用します。
- **SidebarContent** — ヘッダーとフッターの間のスクロール可能な領域。
- **SidebarGroup** — オプションのラベル、アクション、コンテンツエリアを持つ関連ナビゲーションをグループ化します。
- **SidebarMenu** / **SidebarMenuItem** — リンク、バッジ、アクション、ネストされたサブメニューのメニュー構造。
- **SidebarRail** — 適用可能な場合にサイドバーの幅を調整するリサイズハンドル。
- **SidebarInset** — `inset` バリアントを使用するときにメインコンテンツをラップします。
- **SidebarTrigger** — サイドバーの開閉を切り替えるコントロール。

## SidebarProvider

`SidebarProvider` コンポーネントは `Sidebar` コンポーネントにサイドバーコンテキストを提供するために使用されます。アプリケーションは常に `SidebarProvider` コンポーネントでラップする必要があります。

### Props

| Name           | Type                      | Description                                  |
| -------------- | ------------------------- | -------------------------------------------- |
| `defaultOpen`  | `boolean`                 | サイドバーのデフォルトのオープン状態。       |
| `open`         | `boolean`                 | サイドバーのオープン状態（制御あり）。       |
| `onOpenChange` | `(open: boolean) => void` | サイドバーのオープン状態を設定します（制御あり）。 |

### 幅

アプリケーションに単一のサイドバーがある場合、`sidebar.tsx` の `SIDEBAR_WIDTH` と `SIDEBAR_WIDTH_MOBILE` 変数を使ってサイドバーの幅を設定できます。

```tsx showLineNumbers title="components/ui/sidebar.tsx"
const SIDEBAR_WIDTH = "16rem"
const SIDEBAR_WIDTH_MOBILE = "18rem"
```

アプリケーションに複数のサイドバーがある場合は、`style` プロップの `--sidebar-width` と `--sidebar-width-mobile` CSS 変数を使用できます。

```tsx showLineNumbers
<SidebarProvider
  style={
    {
      "--sidebar-width": "20rem",
      "--sidebar-width-mobile": "20rem",
    } as React.CSSProperties
  }
>
  <Sidebar />
</SidebarProvider>
```

### キーボードショートカット

サイドバーをトリガーするには、Mac では `cmd+b`、Windows では `ctrl+b` キーボードショートカットを使用します。

```tsx showLineNumbers title="components/ui/sidebar.tsx"
const SIDEBAR_KEYBOARD_SHORTCUT = "b"
```

## Sidebar

折りたたみ可能なサイドバーをレンダリングするためのメインの `Sidebar` コンポーネント。

### Props

| Property      | Type                              | Description                       |
| ------------- | --------------------------------- | --------------------------------- |
| `side`        | `left` または `right`             | サイドバーの位置。                |
| `variant`     | `sidebar`、`floating`、または `inset` | サイドバーのバリアント。      |
| `collapsible` | `offcanvas`、`icon`、または `none` | サイドバーの折りたたみ状態。     |

| Prop        | Description                                                  |
| ----------- | ------------------------------------------------------------ |
| `offcanvas` | 左右からスライドインする折りたたみ可能なサイドバー。         |
| `icon`      | アイコンに折りたたまれるサイドバー。                         |
| `none`      | 折りたたみ不可のサイドバー。                                 |

<Callout>
  **注意:** `inset` バリアントを使用する場合は、メインコンテンツを `SidebarInset` コンポーネントでラップすることを忘れないでください。
</Callout>

```tsx showLineNumbers
<SidebarProvider>
  <Sidebar variant="inset" />
  <SidebarInset>
    <main>{children}</main>
  </SidebarInset>
</SidebarProvider>
```

## useSidebar

`useSidebar` フックはサイドバーを制御するために使用されます。

```tsx showLineNumbers
import { useSidebar } from "@/components/ui/sidebar"

export function AppSidebar() {
  const {
    state,
    open,
    setOpen,
    openMobile,
    setOpenMobile,
    isMobile,
    toggleSidebar,
  } = useSidebar()
}
```

| Property        | Type                      | Description                                   |
| --------------- | ------------------------- | --------------------------------------------- |
| `state`         | `expanded` または `collapsed` | サイドバーの現在の状態。                  |
| `open`          | `boolean`                 | サイドバーが開いているかどうか。              |
| `setOpen`       | `(open: boolean) => void` | サイドバーのオープン状態を設定します。        |
| `openMobile`    | `boolean`                 | モバイルでサイドバーが開いているかどうか。    |
| `setOpenMobile` | `(open: boolean) => void` | モバイルでのサイドバーのオープン状態を設定します。 |
| `isMobile`      | `boolean`                 | サイドバーがモバイル上にあるかどうか。        |
| `toggleSidebar` | `() => void`              | サイドバーをトグルします。デスクトップとモバイル。 |

## SidebarGroup

`SidebarGroup` コンポーネントを使ってサイドバー内のセクションを作成します。

`SidebarGroup` には `SidebarGroupLabel`、`SidebarGroupContent`、オプションの `SidebarGroupAction` があります。

```tsx showLineNumbers
<SidebarGroup>
  <SidebarGroupLabel>Application</SidebarGroupLabel>
  <SidebarGroupAction>
    <Plus /> <span className="sr-only">Add Project</span>
  </SidebarGroupAction>
  <SidebarGroupContent></SidebarGroupContent>
</SidebarGroup>
```

`SidebarGroup` を折りたたみ可能にするには、`Collapsible` でラップします。

```tsx showLineNumbers
<Collapsible defaultOpen className="group/collapsible">
  <SidebarGroup>
    <SidebarGroupLabel asChild>
      <CollapsibleTrigger>
        Help
        <ChevronDown className="ml-auto transition-transform group-data-[state=open]/collapsible:rotate-180" />
      </CollapsibleTrigger>
    </SidebarGroupLabel>
    <CollapsibleContent>
      <SidebarGroupContent />
    </CollapsibleContent>
  </SidebarGroup>
</Collapsible>
```

## SidebarMenuButton

`SidebarMenuButton` コンポーネントは `SidebarMenuItem` 内にメニューボタンをレンダリングするために使用されます。

デフォルトでは `SidebarMenuButton` はボタンをレンダリングしますが、`asChild` プロップを使って `Link` や `a` タグなど別のコンポーネントをレンダリングできます。

`isActive` プロップを使ってメニューアイテムをアクティブとしてマークします。

```tsx showLineNumbers
<SidebarMenuButton asChild isActive>
  <a href="#">Home</a>
</SidebarMenuButton>
```

## SidebarTrigger

`SidebarTrigger` コンポーネントを使ってサイドバーをトグルするボタンをレンダリングします。

## 制御ありサイドバー

`open` と `onOpenChange` プロップを使ってサイドバーを制御します。

```tsx showLineNumbers
export function AppSidebar() {
  const [open, setOpen] = React.useState(false)

  return (
    <SidebarProvider open={open} onOpenChange={setOpen}>
      <Sidebar />
    </SidebarProvider>
  )
}
```

## 変更履歴

### RTL サポート

以前のバージョンの `Sidebar` コンポーネントからアップグレードする場合は、RTL サポートを追加するために以下の更新を適用する必要があります:

<Steps>

<Step>Sidebar コンポーネントに `dir` プロップを追加します。</Step>

分解されたプロップに `dir` を追加し、モバイル用の `SheetContent` に渡します:

```diff
  function Sidebar({
    side = "left",
    variant = "sidebar",
    collapsible = "offcanvas",
    className,
    children,
+   dir,
    ...props
  }: React.ComponentProps<"div"> & {
    side?: "left" | "right"
    variant?: "sidebar" | "floating" | "inset"
    collapsible?: "offcanvas" | "icon" | "none"
  }) {
```

次にモバイルビューの `SheetContent` に渡します:

```diff
  <Sheet open={openMobile} onOpenChange={setOpenMobile} {...props}>
    <SheetContent
+     dir={dir}
      data-sidebar="sidebar"
      data-slot="sidebar"
      data-mobile="true"
```

<Step>サイドバーコンテナに `data-side` 属性を追加します。</Step>

サイドバーコンテナ要素に `data-side={side}` を追加します:

```diff
  <div
    data-slot="sidebar-container"
+   data-side={side}
    className={cn(
```

<Step>サイドバーコンテナの位置クラスを更新します。</Step>

JavaScript の三項条件クラスを CSS データ属性セレクターに置き換えます:

```diff
  className={cn(
-   "fixed inset-y-0 z-10 hidden h-svh w-(--sidebar-width) transition-[left,right,width] duration-200 ease-linear md:flex",
-   side === "left"
-     ? "left-0 group-data-[collapsible=offcanvas]:left-[calc(var(--sidebar-width)*-1)]"
-     : "right-0 group-data-[collapsible=offcanvas]:right-[calc(var(--sidebar-width)*-1)]",
+   "fixed inset-y-0 z-10 hidden h-svh w-(--sidebar-width) transition-[left,right,width] duration-200 ease-linear md:flex data-[side=left]:left-0 data-[side=right]:right-0 data-[side=left]:group-data-[collapsible=offcanvas]:left-[calc(var(--sidebar-width)*-1)] data-[side=right]:group-data-[collapsible=offcanvas]:right-[calc(var(--sidebar-width)*-1)]",
```

<Step>SidebarRail の位置クラスを更新します。</Step>

`SidebarRail` コンポーネントを更新してレールに物理的な位置を使用します:

```diff
  className={cn(
-   "hover:after:bg-sidebar-border absolute inset-y-0 z-20 hidden w-4 -translate-x-1/2 transition-all ease-linear group-data-[side=left]:-end-4 group-data-[side=right]:start-0 after:absolute after:inset-y-0 after:start-1/2 after:w-[2px] sm:flex",
+   "hover:after:bg-sidebar-border absolute inset-y-0 z-20 hidden w-4 ltr:-translate-x-1/2 rtl:-translate-x-1/2 transition-all ease-linear group-data-[side=left]:-right-4 group-data-[side=right]:left-0 after:absolute after:inset-y-0 after:start-1/2 after:w-[2px] sm:flex",
```

<Step>SidebarTrigger アイコンに RTL フリップを追加します。</Step>

`SidebarTrigger` のアイコンに `className="rtl:rotate-180"` を追加して RTL モードでフリップします:

```diff
  <Button ...>
-   <PanelLeftIcon />
+   <PanelLeftIcon className="rtl:rotate-180" />
    <span className="sr-only">Toggle Sidebar</span>
  </Button>
```

</Steps>

これらの変更を適用した後、`dir` プロップを使って方向を設定できます:

```tsx
<Sidebar dir="rtl" side="right">
  {/* ... */}
</Sidebar>
```

サイドバーは LTR と RTL の両方のレイアウトで正しく自身を配置し、インタラクションを処理します。
