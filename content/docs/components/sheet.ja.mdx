## 使い方

```tsx showLineNumbers
import {
  Sheet,
  SheetClose,
  SheetContent,
  SheetDescription,
  SheetFooter,
  SheetHeader,
  SheetTitle,
  SheetTrigger,
} from "@/components/ui/sheet"
```

```tsx showLineNumbers
<Sheet>
  <SheetTrigger>Open</SheetTrigger>
  <SheetContent>
    <SheetHeader>
      <SheetTitle>Are you absolutely sure?</SheetTitle>
      <SheetDescription>This action cannot be undone.</SheetDescription>
    </SheetHeader>
  </SheetContent>
</Sheet>
```

## コンポジション

`Sheet` を構築するには以下のコンポジションを使用します:

```text
Sheet
├── SheetTrigger
└── SheetContent
    ├── SheetHeader
    │   ├── SheetTitle
    │   └── SheetDescription
    └── SheetFooter
```

## 例

### 位置

`SheetContent` の `side` プロップを使ってシートが表示される画面の端を設定します。値は `top`、`right`、`bottom`、`left` のいずれかです。

<ComponentPreview styleName="base-nova" name="sheet-side" />

### 閉じるボタンなし

`SheetContent` に `showCloseButton={false}` を使って閉じるボタンを非表示にします。
