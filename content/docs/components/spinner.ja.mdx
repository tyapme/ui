12 本のバーが円形に配置され、それぞれが順番にフェードインしてリングを周回するようにハイライトが見えます。アニメーションは SVG 内のスコープ付き CSS キーフレームであり、グローバルスタイルや追加の依存関係はありません。色はデフォルトで `currentColor` なので、`text-*` クラスと周囲のテーマが自動的に適用されます。

## インストール

<ComponentInstall name="spinner" styleName="base-nova" />

## 使い方

```tsx
import { Spinner } from "@/components/ui/spinner"
```

```tsx
<Spinner />
<Spinner size={24} />
<Spinner size={16} color="rgba(255,255,255,0.65)" />
```

## Props

`<svg>` の属性に加えて、以下を受け取ります:

| Prop        | Type     | Default          | Description                        |
| :---------- | :------- | :--------------- | :--------------------------------- |
| `size`      | `number` | `16`             | スピナーのサイズ（ピクセル）。     |
| `color`     | `string` | `"currentColor"` | スピナーバーの色。                 |
| `className` | `string` | -                | 追加の CSS クラス。                |
