**Charts** のご紹介。アプリにコピー＆ペーストできるチャートコンポーネントのコレクションです。

チャートはそのまま美しく表示されるよう設計されています。他のコンポーネントとの相性が良く、プロジェクトに合わせて完全にカスタマイズ可能です。

[チャートライブラリを見る](/charts)。

## コンポーネント

内部では [Recharts](https://recharts.org/) を使用しています。

`chart` コンポーネントはコンポジションを念頭に置いて設計されています。**Recharts コンポーネントを使ってチャートを構築し、`ChartTooltip` などのカスタムコンポーネントは必要な場所でのみ使用します**。

```tsx showLineNumbers /ChartContainer/ /ChartTooltipContent/
import { Bar, BarChart } from "recharts"

import { ChartContainer, ChartTooltipContent } from "@/components/ui/chart"

export function MyChart() {
  return (
    <ChartContainer>
      <BarChart data={data}>
        <Bar dataKey="value" />
        <ChartTooltip content={<ChartTooltipContent />} />
      </BarChart>
    </ChartContainer>
  )
}
```

Recharts をラップしていません。つまり、抽象化に縛られることはありません。新しい Recharts バージョンがリリースされた際は、公式のアップグレードパスに従ってチャートをアップグレードできます。

**コンポーネントはあなたのものです。**

## Recharts v3 へのアップデート

既存のチャートコードを Recharts v3 にアップデートする場合:

- CSS 変数からチャートトークンを参照する際は `hsl(var(--chart-1))` の代わりに `var(--chart-1)` を使用してください。
- 初期ツールチップ状態のみに `ChartTooltip.defaultIndex` を使用してください。永続的なアクティブシェイプは独自のチャートステートで管理してください。
- 親の `<BarChart>` が既に `layout` を定義している場合、`<Bar>` から `layout` を削除してください。
- `ChartContainer` に `height`、`min-h-*`、または `aspect-*` を設定し、`ResponsiveContainer` が初回レンダリング時に測定できるようにしてください。

## チャート設定

チャート設定はチャートのラベル、アイコン、カラーを定義する場所です。

意図的にチャートデータから切り離されています。

これにより、チャート間で設定とカラートークンを共有できます。また、データやカラートークンがリモートや別の形式で存在する場合にも独立して機能します。

```tsx showLineNumbers /ChartConfig/
import { Monitor } from "lucide-react"

import { type ChartConfig } from "@/components/ui/chart"

const chartConfig = {
  desktop: {
    label: "Desktop",
    icon: Monitor,
    // 'hsl(220, 98%, 61%)' や 'var(--color-name)' のような色
    color: "#2563eb",
    // または 'light' と 'dark' キーを持つテーマオブジェクト
    theme: {
      light: "#2563eb",
      dark: "#dc2626",
    },
  },
} satisfies ChartConfig
```

## テーマ

チャートはテーマをサポートしています。CSS 変数（推奨）または hex、hsl、oklch など任意のカラー形式の色の値を使用できます。

### CSS 変数

<Steps className="mb-0 pt-2">

<Step>CSS ファイルにカラーを定義します</Step>

```css title="app/globals.css" showLineNumbers
  :root {
    --chart-1: oklch(0.646 0.222 41.116);
    --chart-2: oklch(0.6 0.118 184.704);
  }

  .dark {
    --chart-1: oklch(0.488 0.243 264.376);
    --chart-2: oklch(0.696 0.17 162.48);
  }
}
```

<Step>`chartConfig` にカラーを追加します</Step>

```tsx title="components/example-chart.tsx" showLineNumbers

    label: "Desktop",
    color: "var(--chart-1)",
  },

    label: "Mobile",

  },

```

</Steps>

### hex、hsl、oklch

チャート設定に直接カラーを定義することもできます。お好みのカラー形式を使用してください。

```tsx title="components/example-chart.tsx" showLineNumbers
const chartConfig = {
  desktop: {
    label: "Desktop",
    color: "#2563eb",
  },
  mobile: {
    label: "Mobile",
    color: "hsl(220, 98%, 61%)",
  },
  tablet: {
    label: "Tablet",
    color: "oklch(0.5 0.2 240)",
  },
  laptop: {
    label: "Laptop",
    color: "var(--chart-2)",
  },
} satisfies ChartConfig
```

### カラーの使用

チャートでテーマカラーを使用するには、`var(--color-KEY)` 形式でカラーを参照します。

#### コンポーネント

```tsx
<Bar dataKey="desktop" fill="var(--color-desktop)" />
```

#### チャートデータ

```tsx title="components/example-chart.tsx" showLineNumbers
const chartData = [
  { browser: "chrome", visitors: 275, fill: "var(--color-chrome)" },
  { browser: "safari", visitors: 200, fill: "var(--color-safari)" },
]
```

#### Tailwind

```tsx title="components/example-chart.tsx"
<LabelList className="fill-(--color-desktop)" />
```

## ツールチップ

チャートのツールチップにはラベル、名前、インジケーター、値が含まれます。これらを組み合わせてツールチップをカスタマイズできます。

<ComponentPreview styleName="base-nova" name="chart-tooltip" hideCode />

`hideLabel`、`hideIndicator` プロパティを使って各要素のオン・オフを切り替え、`indicator` プロパティでインジケータースタイルをカスタマイズできます。

`labelKey` と `nameKey` を使用して、ツールチップのラベルと名前にカスタムキーを指定できます。

Chart には `<ChartTooltip>` と `<ChartTooltipContent>` コンポーネントが付属しています。これらを使ってチャートにカスタムツールチップを追加できます。

```tsx title="components/example-chart.tsx"
import { ChartTooltip, ChartTooltipContent } from "@/components/ui/chart"
```

```tsx title="components/example-chart.tsx"
<ChartTooltip content={<ChartTooltipContent />} />
```

### プロパティ

ツールチップをカスタマイズするには以下のプロパティを使用します。

| プロパティ       | 型                       | 説明                                           |
| :-------------- | :----------------------- | :--------------------------------------------- |
| `labelKey`      | string                   | ラベルに使用する設定またはデータキー             |
| `nameKey`       | string                   | 名前に使用する設定またはデータキー               |
| `indicator`     | `dot` `line` または `dashed` | ツールチップのインジケータースタイル           |
| `hideLabel`     | boolean                  | ラベルを非表示にするかどうか                   |
| `hideIndicator` | boolean                  | インジケーターを非表示にするかどうか           |

### カラー

カラーはチャート設定から自動的に参照されます。

### カスタム

ツールチップのラベルと名前にカスタムキーを使用するには、`labelKey` と `nameKey` プロパティを使用します。

```tsx showLineNumbers /browser/
const chartData = [
  { browser: "chrome", visitors: 187, fill: "var(--color-chrome)" },
  { browser: "safari", visitors: 200, fill: "var(--color-safari)" },
]

const chartConfig = {
  visitors: {
    label: "Total Visitors",
  },
  chrome: {
    label: "Chrome",
    color: "var(--chart-1)",
  },
  safari: {
    label: "Safari",
    color: "var(--chart-2)",
  },
} satisfies ChartConfig
```

```tsx title="components/example-chart.tsx"
<ChartTooltip
  content={<ChartTooltipContent labelKey="visitors" nameKey="browser" />}
/>
```

ラベルには `Total Visitors`、ツールチップ名には `Chrome` と `Safari` が使用されます。
