## インストール

Date Picker は `<Popover />` と `<Calendar />` コンポーネントを組み合わせて構築されています。

[Popover](/docs/components/popover#installation) と [Calendar](/docs/components/calendar#installation) コンポーネントのインストール手順を参照してください。

## 構成

デートピッカーは `Popover` と `Calendar` から構築されます（`DatePicker` ルートコンポーネントはありません）:

```text
Popover
├── PopoverTrigger
└── PopoverContent
    └── Calendar
```
