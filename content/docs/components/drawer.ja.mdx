## について

Drawer は [emilkowalski](https://twitter.com/emilkowalski) による [Vaul](https://github.com/emilkowalski/vaul) の上に構築されています。

## インストール

<ComponentInstall name="drawer" styleName="base-nova" />

## 使い方

```tsx showLineNumbers
import {
  Drawer,
  DrawerClose,
  DrawerContent,
  DrawerDescription,
  DrawerFooter,
  DrawerHeader,
  DrawerTitle,
  DrawerTrigger,
} from "@/components/ui/drawer"
```

```tsx showLineNumbers
<Drawer>
  <DrawerTrigger>Open</DrawerTrigger>
  <DrawerContent>
    <DrawerHeader>
      <DrawerTitle>Are you absolutely sure?</DrawerTitle>
      <DrawerDescription>This action cannot be undone.</DrawerDescription>
    </DrawerHeader>
    <DrawerFooter>
      <Button>Submit</Button>
      <DrawerClose>
        <Button variant="outline">Cancel</Button>
      </DrawerClose>
    </DrawerFooter>
  </DrawerContent>
</Drawer>
```

## 構成

`Drawer` を構築するには以下の構成を使用します:

```text
Drawer
├── DrawerTrigger
└── DrawerContent
    ├── DrawerHeader
    │   ├── DrawerTitle
    │   └── DrawerDescription
    └── DrawerFooter
```

## 例

### スクロール可能なコンテンツ

コンテンツがスクロールしても操作ボタンを常に表示します。

<ComponentPreview styleName="base-nova" name="drawer-scrollable-content" />

### 表示位置

`direction` プロパティを使用してドロワーの表示位置を設定します。利用可能なオプションは `top`、`right`、`bottom`、`left` です。

<ComponentPreview styleName="base-nova" name="drawer-sides" />

### レスポンシブダイアログ

`Dialog` と `Drawer` コンポーネントを組み合わせてレスポンシブなダイアログを作成できます。デスクトップでは `Dialog`、モバイルでは `Drawer` としてレンダリングされます。

<ComponentPreview styleName="base-nova" name="drawer-dialog" />
