title: スキル
description: AI アシスタントに shadcn/ui コンポーネント、パターン、ベストプラクティスの深い知識を与えます。
---

スキルは Claude Code などの AI アシスタントに shadcn/ui に関するプロジェクト対応のコンテキストを提供します。インストールすると、AI アシスタントがプロジェクトに適した正しい API とパターンを使って、コンポーネントの検索・インストール・組み合わせ・カスタマイズができるようになります。

例えば、AI アシスタントに以下のように依頼できます：

- _「メールとパスワードフィールドを含むログインフォームを追加して。」_
- _「プロフィール情報を更新するフォームを含む設定ページを作成して。」_
- _「サイドバー、統計カード、データテーブルを含むダッシュボードを作成して。」_
- _「--preset [CODE] に切り替えて」_
- _「@tailark からヒーローを追加できる？」_

スキルはプロジェクトの `components.json` を読み取り、フレームワーク、alias、インストール済みコンポーネント、アイコンライブラリ、ベースライブラリを AI アシスタントに提供することで、初回から正しいコードを生成できるようにします。

---

## インストール

```bash
npx skills add shadcn/ui
```

これにより shadcn スキルがプロジェクトにインストールされます。インストール後、AI アシスタントは shadcn/ui コンポーネントを扱う際に自動的にロードします。

スキルの詳細は [skills.sh](https://skills.sh) で確認できます。

---

## 含まれる内容

スキルは AI アシスタントに以下の知識を提供します：

### プロジェクトコンテキスト

毎回のやり取りで、スキルは `shadcn info --json` を実行してプロジェクトの設定を取得します：フレームワーク、Tailwind バージョン、alias、ベースライブラリ（`radix` または `base`）、アイコンライブラリ、インストール済みコンポーネント、解決済みのファイルパス。

### CLI コマンド

すべての CLI コマンドの完全リファレンス：`init`、`add`、`search`、`view`、`docs`、`diff`、`info`、`build`。フラグ、ドライランモード、スマートマージワークフロー、プリセット、テンプレートを含みます。

### テーマとカスタマイズ

CSS 変数、OKLCH カラー、ダークモード、カスタムカラー、ボーダー半径、コンポーネントバリアントの仕組み。Tailwind v3 と v4 の両方に対するガイダンスを含みます。

### レジストリ作成

カスタムコンポーネントレジストリのビルドと公開方法：`registry.json` フォーマット、アイテムタイプ、ファイルオブジェクト、依存関係、CSS 変数、ビルド、ホスティング、ユーザー設定。

### MCP サーバー

AI アシスタントがレジストリからコンポーネントを検索・閲覧・インストールできる shadcn MCP サーバーのセットアップとツール。

## 仕組み

1. **プロジェクト検出** — スキルはプロジェクト内に `components.json` ファイルを見つけると有効化されます。
2. **コンテキスト注入** — `shadcn info --json` を実行してプロジェクト設定を読み取り、結果をアシスタントのコンテキストに注入します。
3. **パターン強制** — アシスタントは shadcn/ui の組み合わせルールに従います：フォームには `FieldGroup`、オプションセットには `ToggleGroup`、セマンティックカラー、正しいベース固有の API を使用。
4. **コンポーネント探索** — アシスタントはコードを生成する前に `shadcn docs`、`shadcn search`、または MCP ツールを使ってコンポーネントとそのドキュメントを探します。
