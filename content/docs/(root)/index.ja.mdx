Ketyap UI は、Ketyap プロダクト画面全体で使用されるコンポーネント、テーマ、フォームパターン、実装ルールをまとめたものです。

目的は、画面ごとに例外を追加することなく、プロダクト UI の一貫性を保つことです。

## 原則

- **一貫性：** コンポーネント、スペーシング、カラー、タイポグラフィを共通ルールに揃える。
- **再利用：** 繰り返し現れる UI の役割はページ固有のフラグメントではなく、共有コンポーネントとして扱う。
- **メンテナビリティ：** 実装、テスト、ドキュメントを同じ変更で更新する。
- **プロダクトフォーカス：** UI の範囲を Ketyap プロダクトのニーズに限定する。

## はじめ方

[インストール](/docs/installation) から始めて、[コンポーネント](/docs/components/accordion) を閲覧してください。
