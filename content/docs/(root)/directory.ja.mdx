これらのレジストリは追加設定なしで CLI に組み込まれています。コンポーネントを追加するには `npx shadcn add @<registry>/<component>` を実行してください。

<Callout className="bg-muted font-semibold">
  コミュニティレジストリはサードパーティの開発者によって管理されています。インストール前に必ずコードを確認し、セキュリティと品質基準を満たしていることを確かめてください。
</Callout>

レジストリが見つかりませんか？[こちら](/docs/registry/registry-index)でレジストリの追加方法を確認してください。

<DirectoryList />

## ドキュメント

`shadcn` CLI を使って独自のコードレジストリを運営できます。独自レジストリを使うことで、カスタムコンポーネント、フック、ページ、設定、ルール、その他のファイルを任意のプロジェクトに配布できます。
