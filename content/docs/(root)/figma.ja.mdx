## 無料

- [shadcn/ui components](https://www.figma.com/community/file/1342715840824755935) by [Sitsiilia Bergmann](https://x.com/sitsiilia) - shadcn コンポーネントシステムに準拠した、定期的にメンテナンスされている構造化されたコンポーネントライブラリ。
- [shadcn/ui design system](https://www.figma.com/community/file/1203061493325953101) by [Pietro Schirano](https://twitter.com/skirano) - shadcn/ui のデザインコンパニオン。各コンポーネントはコードの実装に完璧に一致するよう丁寧に作成されています。

## 有料

- [shadcn/ui kit](https://shadcndesign.com) by [Matt Wierzbicki](https://x.com/matsugfx) - shadcn/ui 互換でスムーズなデザインから開発への引き継ぎに最適化された、常に最新のプレミアム Figma UI キット。
- [shadcncraft Design System](https://shadcncraft.com) - Pro React ブロックと 1:1 の Figma 対応を備えたプロダクション対応の shadcn/ui キット。tweakcn テーマ、AI 支援ワークフロー、Figma から React へのエクスポートで実際のプロダクト UI をより速く設計・リリース。
- [shadcn/studio UI Kit](https://shadcnstudio.com/figma) - 更新されたコンポーネント、550+ ブロック、10+ テンプレート、20+ テーマ、そしてデザインを shadcn/ui コードに変換する AI ツールを備えた shadcn/ui 互換の Figma キットでデザインと開発を加速。
- [Shadcnblocks.com](https://www.shadcnblocks.com) - コンポーネント、500+ プロブロック、shadcn テーマ変数、ライト/ダークモード、Figma MCP 対応のプレミアム Shadcn Figma UI キット。
- [Obra shadcn/ui Pro](https://shadcn.obra.studio/products/obra-shadcn-ui-pro) by [Obra Studio](https://obra.studio/) - 作業をこなしたいデザイナー向けに特化 — Figma 内で shadcn/ui を使う最高のデザイナー体験。shadcn との変数の一貫性、カスタムコンポーネント、Pro ブロック、デザインからコードへのプラグインを搭載。
