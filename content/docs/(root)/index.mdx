Ketyap UI collects the components, themes, form patterns, and implementation rules used across Ketyap product screens.

The goal is to keep product UI consistent without adding one-off exceptions for every screen.

## Principles

- **Consistency:** Align components, spacing, color, and typography around shared rules.
- **Reuse:** Treat repeated UI roles as shared components, not page-specific fragments.
- **Maintainability:** Update implementation, tests, and documentation in the same change.
- **Product focus:** Keep the UI surface scoped to Ketyap product needs.
