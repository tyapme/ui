---

<Callout className="mb-6 border-emerald-600 bg-emerald-100 dark:border-emerald-400 dark:bg-emerald-900">

**新しいプロジェクトを始める場合は、** [shadcn/create](/create?template=start&base=base&rtl=true) を使うと、カスタムテーマ・Base UI または Radix・アイコンライブラリが設定済みの TanStack Start アプリを作成できます。

</Callout>

<Steps>

### プロジェクトを作成

`--rtl` フラグと `start` テンプレートを使って新しいプロジェクトを作成します。

**[shadcn/create](/create?template=start&base=base&rtl=true) でプロジェクトを作成済みの場合は、このステップをスキップできます。**

```bash
npx shadcn@latest create --template start --rtl
```

これにより、`rtl: true` フラグを持つ `components.json` ファイルが作成されます。

```json title="components.json" showLineNumbers {4}
{
  "$schema": "https://ui.shadcn.com/schema.json",
  "style": "base-nova",
  "rtl": true
}
```

### DirectionProvider を追加

`html` タグに `dir="rtl"` と `lang="ar"` 属性を追加します。`lang="ar"` は対象言語に合わせて変更してください。

次に、`__root.tsx` でアプリを `DirectionProvider` コンポーネントで `direction="rtl"` プロパティを指定してラップします。

```tsx title="src/routes/__root.tsx" showLineNumbers {1,9,14-16}
import { DirectionProvider } from "@/components/ui/direction"

export const Route = createRootRoute({
  component: RootComponent,
})

function RootComponent() {
  return (
    <html lang="ar" dir="rtl">
      <head>
        <Meta />
      </head>
      <body>
        <DirectionProvider direction="rtl">{children}</DirectionProvider>
        <Scripts />
      </body>
    </html>
  )
}
```

### フォントを追加

最良の RTL 体験のために、対象言語を適切にサポートするフォントの使用をお勧めします。[Noto](https://fonts.google.com/noto) はこの目的に適したフォントファミリーで、Inter や Geist とも相性が良いです。

[Fontsource](https://fontsource.org/fonts/noto-sans-arabic) を使ってフォントをインストールします。

```bash
npm install @fontsource-variable/noto-sans-arabic
```

`styles.css` にフォントをインポートします。

```css title="src/styles.css" showLineNumbers {4,7}
@import "tailwindcss";
@import "tw-animate-css";
@import "shadcn/tailwind.css";
@import "@fontsource-variable/noto-sans-arabic";

@theme inline {
  --font-sans: "Noto Sans Arabic Variable", sans-serif;
}
```

ヘブライ語などの他の言語には `@fontsource-variable/noto-sans-hebrew` を使用できます。

### コンポーネントを追加

プロジェクトにコンポーネントを追加する準備ができました。RTL サポートの対応は CLI が自動的に行います。

```bash
npx shadcn@latest add item
```

</Steps>
