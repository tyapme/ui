### 新しい CLI

この数週間、新しい CLI の開発に取り組んできました。完全な書き直しで、多くの新機能と改善が含まれています。

### `init`

```bash
npx shadcn@latest init
```

`init` コマンドを実行すると、`components.json` を設定するためにいくつかの質問が表示されます：

```txt showLineNumbers
Which style would you like to use? › Default
Which color would you like to use as base color? › Slate
Where is your global CSS file? › › app/globals.css
Do you want to use CSS variables for colors? › no / yes
Where is your tailwind.config.js located? › tailwind.config.js
Configure the import alias for components: › @/components
Configure the import alias for utils: › @/lib/utils
Are you using React Server Components? › no / yes
```

このファイルにはコンポーネントに関するすべての情報が含まれています：インストール先、インポートパス、スタイルの設定方法などです。

このファイルを使用して、コンポーネントのインポートパスの変更、baseColor の設定、スタイル方法の変更が可能です。

```json title="components.json" showLineNumbers
{
  "style": "default",
  "tailwind": {
    "config": "tailwind.config.ts",
    "css": "src/app/globals.css",
    "baseColor": "zinc",
    "cssVariables": true
  },
  "rsc": false,
  "aliases": {
    "utils": "~/lib/utils",
    "components": "~/components"
  }
}
```

これにより、`src` や `app` ディレクトリを含む任意のディレクトリ構造で CLI を使用できるようになりました。

### `add`

```bash
npx shadcn@latest add
```

`add` コマンドがより強力になりました。UI コンポーネントの追加だけでなく、より複雑なコンポーネントのインポートも可能です（近日公開予定）。

CLI はすべてのコンポーネントと依存関係を自動的に解決し、カスタム設定に基づいてフォーマットし、プロジェクトに追加します。

### `diff`（実験的）

```bash
npx shadcn diff
```

アップストリームの更新を追跡するための新しい `diff` コマンドも導入しています。

このコマンドを使用して、アップストリームリポジトリの変更点を確認し、それに応じてプロジェクトを更新できます。

`diff` コマンドを実行すると、更新可能なコンポーネントの一覧が表示されます：

```bash
npx shadcn diff
```

```txt
The following components have updates available:
- button
  - /path/to/my-app/components/ui/button.tsx
- toast
  - /path/to/my-app/components/ui/use-toast.ts
  - /path/to/my-app/components/ui/toaster.tsx
```

その後、`diff [component]` を実行して変更内容を確認できます：

```bash
npx shadcn diff alert
```

```diff /pl-12/
const alertVariants = cva(
- "relative w-full rounded-lg border",
+ "relative w-full pl-12 rounded-lg border"
)
```

### CSS 変数または Tailwind カラーによるテーマ設定

テーマ設定に CSS 変数または Tailwind CSS ユーティリティクラスを選択できます。

新しいコンポーネントを追加する際、CLI は `components.json` の設定に基づいて正しいテーマ設定方法を自動的に使用します。

#### ユーティリティクラス

```tsx /bg-zinc-950/ /text-zinc-50/ /dark:bg-white/ /dark:text-zinc-950/
<div className="bg-zinc-950 dark:bg-white" />
```

テーマ設定にユーティリティクラスを使用するには、`components.json` ファイルで `tailwind.cssVariables` を `false` に設定してください。

```json {6} title="components.json" showLineNumbers
{
  "tailwind": {
    "config": "tailwind.config.js",
    "css": "app/globals.css",
    "baseColor": "slate",
    "cssVariables": false
  }
}
```

#### CSS 変数

```tsx /bg-background/ /text-foreground/
<div className="bg-background text-foreground" />
```

テーマ設定に CSS 変数クラスを使用するには、`components.json` ファイルで `tailwind.cssVariables` を `true` に設定してください。

```json {6} title="components.json" showLineNumbers
{
  "tailwind": {
    "config": "tailwind.config.js",
    "css": "app/globals.css",
    "baseColor": "slate",
    "cssVariables": true
  }
}
```

### ベースカラー

プロジェクトのベースカラーを設定できるようになりました。これはコンポーネントのデフォルトカラーパレットの生成に使用されます。

```json {5} title="components.json" showLineNumbers
{
  "tailwind": {
    "config": "tailwind.config.js",
    "css": "app/globals.css",
    "baseColor": "zinc",
    "cssVariables": false
  }
}
```

`gray`、`neutral`、`slate`、`stone`、`zinc` から選択してください。

`cssVariables` が `true` の場合、`globals.css` ファイルにベースカラーを CSS 変数として設定します。`cssVariables` が `false` の場合、コンポーネントに Tailwind CSS ユーティリティクラスをインライン展開します。

### React Server Components

React Server Components をサポートしていないフレームワークを使用している場合、`rsc` を `false` に設定して無効化できるようになりました。コンポーネントを追加する際に `use client` ディレクティブが自動的に追加または削除されます。

```json title="components.json" showLineNumbers
{
  "rsc": false
}
```

### スタイル

_スタイル_ という新しいコンセプトを導入しています。

_スタイルは視覚的な基盤として考えることができます：形状、アイコン、アニメーション、タイポグラフィ。_ スタイルには独自のコンポーネント、アニメーション、アイコンなどが含まれます。

`default` と `new-york` の 2 つのスタイルを提供しています（さらに追加予定）。

`default` スタイルはこれまで使用してきたスタイルです。このプロジェクトの開始当初から使用しているスタイルで、アイコンに `lucide-react`、アニメーションに `tailwindcss-animate` を使用しています。

`new-york` スタイルは新しいスタイルです。小さめのボタン、シャドウ付きカード、[Radix Icons](https://icons.radix-ui.com) の新しいアイコンセットが含まれています。

```json title="components.json" showLineNumbers
{
  "style": "new-york"
}
```

### プロジェクトの更新

コピー＆ペーストのアプローチを採用しているため、最新の変更を取得するにはプロジェクトを手動で更新する必要があります。

<Callout className="mt-4">
  注意：アップストリームの更新を追跡するための [`diff`](#diff-experimental) コマンドを開発中です。
</Callout>

<Steps>

### `components.json` を追加する

ルートに `components.json` ファイルを作成します：

```json title="components.json" showLineNumbers
{
  "style": "default",
  "rsc": true,
  "tailwind": {
    "config": "tailwind.config.js",
    "css": "app/globals.css",
    "baseColor": "slate",
    "cssVariables": true
  },
  "aliases": {
    "components": "@/components",
    "utils": "@/lib/utils"
  }
}
```

プロジェクト構造に合わせて `tailwind.css` と `aliases` の値を更新してください。

### Button

`buttonVariants` に `icon` サイズを追加します：

```tsx {7} title="components/ui/button.tsx" showLineNumbers
const buttonVariants = cva({
  variants: {
    size: {
      default: "h-10 px-4 py-2",
      sm: "h-9 rounded-md px-3",
      lg: "h-11 rounded-md px-8",
      icon: "h-10 w-10",
    },
  },
})
```

### Sheet

1. `sheet.tsx` の内容を以下に置き換えます：

```tsx title="components/ui/sheet.tsx" showLineNumbers
"use client"

import * as React from "react"
import * as SheetPrimitive from "@radix-ui/react-dialog"
import { cva, type VariantProps } from "class-variance-authority"
import { X } from "lucide-react"

import { cn } from "@/lib/utils"

const Sheet = SheetPrimitive.Root

const SheetTrigger = SheetPrimitive.Trigger

const SheetClose = SheetPrimitive.Close

const SheetPortal = ({
  className,
  ...props
}: SheetPrimitive.DialogPortalProps) => (
  <SheetPrimitive.Portal className={cn(className)} {...props} />
)
SheetPortal.displayName = SheetPrimitive.Portal.displayName

const SheetOverlay = React.forwardRef<
  React.ElementRef<typeof SheetPrimitive.Overlay>,
  React.ComponentPropsWithoutRef<typeof SheetPrimitive.Overlay>
>(({ className, ...props }, ref) => (
  <SheetPrimitive.Overlay
    className={cn(
      "fixed inset-0 z-50 bg-background/80 backdrop-blur-sm data-[state=closed]:animate-out data-[state=closed]:fade-out-0 data-[state=open]:animate-in data-[state=open]:fade-in-0",
      className
    )}
    {...props}
    ref={ref}
  />
))
SheetOverlay.displayName = SheetPrimitive.Overlay.displayName

const sheetVariants = cva(
  "fixed z-50 gap-4 bg-background p-6 shadow-lg transition ease-in-out data-[state=closed]:animate-out data-[state=closed]:duration-300 data-[state=open]:animate-in data-[state=open]:duration-500",
  {
    variants: {
      side: {
        top: "inset-x-0 top-0 border-b data-[state=closed]:slide-out-to-top data-[state=open]:slide-in-from-top",
        bottom:
          "inset-x-0 bottom-0 border-t data-[state=closed]:slide-out-to-bottom data-[state=open]:slide-in-from-bottom",
        left: "inset-y-0 left-0 h-full w-3/4 border-r data-[state=closed]:slide-out-to-left data-[state=open]:slide-in-from-left sm:max-w-sm",
        right:
          "inset-y-0 right-0 h-full w-3/4 border-l data-[state=closed]:slide-out-to-right data-[state=open]:slide-in-from-right sm:max-w-sm",
      },
    },
    defaultVariants: {
      side: "right",
    },
  }
)

interface SheetContentProps
  extends React.ComponentPropsWithoutRef<typeof SheetPrimitive.Content>,
    VariantProps<typeof sheetVariants> {}

const SheetContent = React.forwardRef<
  React.ElementRef<typeof SheetPrimitive.Content>,
  SheetContentProps
>(({ side = "right", className, children, ...props }, ref) => (
  <SheetPortal>
    <SheetOverlay />
    <SheetPrimitive.Content
      ref={ref}
      className={cn(sheetVariants({ side }), className)}
      {...props}
    >
      {children}
      <SheetPrimitive.Close className="absolute top-4 right-4 rounded-sm opacity-70 ring-offset-background transition-opacity hover:opacity-100 focus:ring-2 focus:ring-ring focus:ring-offset-2 focus:outline-none disabled:pointer-events-none data-[state=open]:bg-secondary">
        <X className="h-4 w-4" />
        <span className="sr-only">Close</span>
      </SheetPrimitive.Close>
    </SheetPrimitive.Content>
  </SheetPortal>
))
SheetContent.displayName = SheetPrimitive.Content.displayName

const SheetHeader = ({
  className,
  ...props
}: React.HTMLAttributes<HTMLDivElement>) => (
  <div
    className={cn(
      "flex flex-col space-y-2 text-center sm:text-left",
      className
    )}
    {...props}
  />
)
SheetHeader.displayName = "SheetHeader"

const SheetFooter = ({
  className,
  ...props
}: React.HTMLAttributes<HTMLDivElement>) => (
  <div
    className={cn(
      "flex flex-col-reverse sm:flex-row sm:justify-end sm:space-x-2",
      className
    )}
    {...props}
  />
)
SheetFooter.displayName = "SheetFooter"

const SheetTitle = React.forwardRef<
  React.ElementRef<typeof SheetPrimitive.Title>,
  React.ComponentPropsWithoutRef<typeof SheetPrimitive.Title>
>(({ className, ...props }, ref) => (
  <SheetPrimitive.Title
    ref={ref}
    className={cn("text-lg font-semibold text-foreground", className)}
    {...props}
  />
))
SheetTitle.displayName = SheetPrimitive.Title.displayName

const SheetDescription = React.forwardRef<
  React.ElementRef<typeof SheetPrimitive.Description>,
  React.ComponentPropsWithoutRef<typeof SheetPrimitive.Description>
>(({ className, ...props }, ref) => (
  <SheetPrimitive.Description
    ref={ref}
    className={cn("text-sm text-muted-foreground", className)}
    {...props}
  />
))
SheetDescription.displayName = SheetPrimitive.Description.displayName

export {
  Sheet,
  SheetTrigger,
  SheetClose,
  SheetContent,
  SheetHeader,
  SheetFooter,
  SheetTitle,
  SheetDescription,
}
```

2. `position` を `side` に名前変更します

```diff /position/ /side/
- <Sheet position="right" />
+ <Sheet side="right" />
```
