Luma は次のアプリの新しい土台となります。コンポーネントに柔らかなサーフェス、よりオープンなスペーシング、落ち着いたビジュアルリズムをもたらしながら、同じ shadcn/ui のワークフローを維持します。

他の新スタイルと同様に、Luma はテーマ変更にとどまりません。コンポーネントの形状、スペーシング、質感を変えることで、アプリが異なるビジュアルベースラインからスタートします。

Radix と Base UI の両方で [shadcn/create](/create) から今すぐ利用できます。
