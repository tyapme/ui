最初のコミットから、shadcn/ui の目標はカスタマイズ可能にすることでした。

スペーシング、カラートークン、アニメーション、アクセシビリティといった堅実なデフォルト値を提供し、そこから自分でカスタマイズできるようにする。コードをいじり、新しいコンポーネントを追加し、色を変えて、自分だけのバージョンを作る、というのがコンセプトです。

でも、気づいたらすべてのアプリが同じ見た目になってしまっていました。デフォルト値が _良すぎた_ のかもしれません。ごめんなさい。

そこで今日、それを変えます：**npx shadcn create**。

すべてをカスタマイズしましょう。コンポーネントライブラリ、アイコン、ベースカラー、テーマ、フォントを選んで、自分だけの shadcn/ui を作れます。

まず **5 つの新しいビジュアルスタイル** から始めます。UI を本当に _あなたの_ UI らしく見せるためのスタイルです。

- **Vega** – 定番の shadcn/ui スタイル。
- **Nova** – コンパクトなレイアウト向けに padding と margin を抑えたスタイル。
- **Maia** – 柔らかく丸みのある、余白たっぷりのスタイル。
- **Lyra** – 角張ったシャープなスタイル。モノスペースフォントとの相性が抜群。
- **Mira** – コンパクト。密度の高いインターフェース向け。

**これはテーマ変更にとどまりません。**

設定を変えるだけで色が変わるのではなく、あなたのセットアップに合わせてコンポーネントのコード自体が書き直されます。フォント、スペーシング、構造、さらに使用するライブラリまで、すべてが好みに合わせて変わります。

新しい CLI がすべてを処理します。

まずコンポーネントライブラリを選びましょう。Radix または Base UI から選択できます。

Base UI 向けにすべてのコンポーネントを作り直しましたが、同じ抽象化を維持しています。
リモート registry から取得したコンポーネントを含む既存のコンポーネントと完全に互換性があります。

コンポーネントを取得すると、使用しているライブラリを自動検出して適切な変換を適用します。

**今こそ、他とは違う何かを作る時です。**

Next.js、Vite、TanStack Start、v0 でご利用いただけます。
