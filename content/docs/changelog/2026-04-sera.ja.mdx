Sera は印刷デザインの原則に基づいたタイポグラフィファーストのスタイルです。セリフ体のヘディングとサンセリフ体の本文テキストを組み合わせ、角のある形状、大文字のトラッキング、下線付きコントロールを使ってアプリにエディトリアルな雰囲気を生み出します。

他の新スタイルと同様に、Sera はテーマ変更にとどまりません。コンポーネントの形状、スペーシング、質感を変えることで、アプリが異なるビジュアルベースラインからスタートします。

Radix と Base UI の両方で [shadcn/create](/create) から今すぐ利用できます。
