より多くの機能をサポートするためにレジストリスキーマを更新しています。

コードをフラットな JSON ファイルとして定義し、CLI 経由で配布します。

- カスタムスタイル：独自のデザインシステム、コンポーネント、トークンを持ち込む
- サードパーティレジストリや LLM からのコンポーネントの拡張、オーバーライド、ミックス＆マッチ
- テーマ、CSS 変数、hooks、アニメーション、Tailwind レイヤー＆ユーティリティのインストール
