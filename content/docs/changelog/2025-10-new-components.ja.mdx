今回のコンポーネント群は、毎日の開発で何度も作り直している地味なものに注目し、実際に使えるコンポーネントに仕上げました。

**これらのコンポーネントは Radix、Base UI、React Aria など、あらゆるコンポーネントライブラリで動作します。プロジェクトにコピー＆ペーストするだけで使えます。**

- [Spinner](#spinner): ローディング状態を示すインジケーター。
- [Kbd](#kbd): キーボードのキーやキーグループを表示する。
- [Button Group](#button-group): アクションや分割ボタン用のボタングループ。
- [Input Group](#input-group): アイコン、ボタン、ラベルなどを付加した Input。
- [Field](#field): 1 つのコンポーネントでフォームのすべてを担う。
- [Item](#item): アイテムリスト、カードなどを表示する。
- [Empty](#empty): 空の状態を表示するのに使う。

### Spinner

まずは簡単なものから：**Spinner** と **Kbd** です。どちらも基本的なコンポーネントで、何をするかは皆さんご存知の通りです。


### Kbd

Kbd はキーボードのキーを表示するコンポーネントです。

```tsx
import { Kbd, KbdGroup } from "@/components/ui/kbd"
```

```tsx
<Kbd>Ctrl</Kbd>
```

`KbdGroup` を使うとキーボードのキーをグループ化できます。

```tsx showLineNumbers
<KbdGroup>
  <Kbd>Ctrl</Kbd>
  <Kbd>B</Kbd>
</KbdGroup>
```

<ComponentPreview
  name="kbd-demo"

/>

ボタン、ツールチップ、Input Group などに追加できます。

### Button Group

多くのリクエストをいただいた Button Group です。関連するボタンを一貫したスタイルでまとめるコンテナです。アクショングループや分割ボタンなどに最適です。

<ComponentPreview
  name="button-group-demo"

/>

コード例：

```tsx
import { ButtonGroup } from "@/components/ui/button-group"
```

```tsx showLineNumbers
<ButtonGroup>
  <Button>Button 1</Button>
  <Button>Button 2</Button>
</ButtonGroup>
```

Button Group をネストすることで、スペース付きのより複雑なレイアウトを作成できます。

```tsx showLineNumbers
<ButtonGroup>
  <ButtonGroup>
    <Button>Button 1</Button>
    <Button>Button 2</Button>
  </ButtonGroup>
  <ButtonGroup>
    <Button>Button 3</Button>
    <Button>Button 4</Button>
  </ButtonGroup>
</ButtonGroup>
```

`ButtonGroupSeparator` を使うと分割ボタンが作れます。クラシックなドロップダウンパターンです。

<ComponentPreview
  name="button-group-dropdown"

/>

Input にプレフィックスやサフィックスのボタン・テキストを追加するのにも使えます。

<ComponentPreview
  name="button-group-select"

/>

```tsx showLineNumbers
<ButtonGroup>
  <ButtonGroupText>Prefix</ButtonGroupText>
  <Input placeholder="Type something here..." />
  <Button>Button</Button>
</ButtonGroup>
```

### Input Group

Input Group を使うと、Input にアイコン、ボタンなどを追加できます。Input の周りにいつも必要な小さなパーツをまとめたものです。

```tsx
  InputGroup,
  InputGroupAddon,
  InputGroupInput,
```


### Field

**Field** を紹介します。非常に複雑なフォームを構築するためのコンポーネントです。この抽象化は美しい。

完成するまで時間がかかりましたが、Server Actions、React Hook Form、TanStack Form、自前のフォームライブラリなど、あらゆるフォームライブラリと連携できるようにしました。

```tsx
import {
  Field,
  FieldDescription,
  FieldError,
  FieldLabel,
} from "@/components/ui/field"
```

Input 付きの基本的な Field：

```tsx showLineNumbers
<Field>
  <FieldLabel htmlFor="username">Username</FieldLabel>
  <Input id="username" placeholder="Max Leiter" />
  <FieldDescription>
    Choose a unique username for your account.
  </FieldDescription>
</Field>
```

/>

### Item

これはほぼあらゆるコンテンツを収められるシンプルな flex コンテナです。

何度も自分で作ってきたので、コンポーネント化することにしました。今では常に使っています。アイテムリスト、カードなどの表示に活用しています。

```tsx
import {
  Item,
  ItemContent,
  ItemDescription,
  ItemMedia,
  ItemTitle,
} from "@/components/ui/item"
```

基本的な Item：

```tsx showLineNumbers
<Item>

    <ItemDescription>Overview of your account and activity.</ItemDescription>
```

### Empty

最後は **Empty** です。アプリの空の状態を表示するために使います。

```tsx
import {
  Empty,
  EmptyContent,
  EmptyDescription,
  EmptyMedia,
  EmptyTitle,
} from "@/components/ui/empty"
```

使い方：

```tsx showLineNumbers
<Empty>
  <EmptyMedia variant="icon">
    <InboxIcon />
  </EmptyMedia>
  <EmptyTitle>No messages</EmptyTitle>
  <EmptyDescription>You don't have any messages yet.</EmptyDescription>
  <EmptyContent>
    <Button>Send a message</Button>
  </EmptyContent>
</Empty>
```
