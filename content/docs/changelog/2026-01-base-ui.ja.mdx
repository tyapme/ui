12 月に `npx shadcn create` をリリースした際、Radix と Base UI のどちらをコンポーネントライブラリとして選択できる機能を導入しました。本日は、すべての Base UI コンポーネントに関する完全なドキュメントを追加します。

### 新機能

- **Base UI の完全なドキュメント** - すべてのコンポーネントに Base UI 専用のドキュメントが追加され、使い方・プロパティ・サンプルを網羅しています。
- **サンプルを再構築** - すべてのコンポーネントサンプルを Radix と Base UI の両方で再構築しました。切り替えて実装の違いを確認できます。
- **並べて比較** - ドキュメントでは、両ライブラリ間でコンポーネントの動作を簡単に比較できます。

### 同じ抽象化、異なる Primitive

目標は変わりません：どの primitive ライブラリを選んでも一貫した API を提供することです。コンポーネントの見た目と動作は同じで、変わるのは内部の実装だけです。

```tsx
// Works the same whether you're using Radix or Base UI.
import { Dialog, DialogContent, DialogTrigger } from "@/components/ui/dialog"
```

新しいプロジェクトを始める場合は、`npx shadcn create` を実行して好みのライブラリを選択してください。CLI が残りを処理します。
