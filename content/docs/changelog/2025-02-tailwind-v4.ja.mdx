Tailwind v4 と React 19 の最初のプレビューをリリースしました。今日から試すことができます。

新機能：

- CLI で Tailwind v4 を使用したプロジェクトの初期化が可能になりました。
- 新しい @theme ディレクティブと @theme inline オプションへの完全対応。
- 全コンポーネントが Tailwind v4 と React 19 向けに更新されました。
- forwardRef を削除し、型を調整しました。
- すべてのプリミティブにスタイリング用の data-slot 属性が追加されました。
- コンポーネントのスタイルを修正・整理しました。
- toast コンポーネントを非推奨とし、sonner を推奨するようになりました。
- ボタンがデフォルトカーソルを使用するようになりました。
- default スタイルを非推奨とし、新しいプロジェクトは new-york を使用するようになりました。
- HSL カラーが OKLCH に変換されるようになりました。

詳細は[ドキュメント](/docs/tailwind-v4)をご覧ください。
