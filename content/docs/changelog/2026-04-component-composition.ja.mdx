コンポーネントのドキュメント全体に **Composition** セクションを追加しました。正しい構造を一目で確認できます：何が何をラップするか、どのサブコンポーネントが一緒に使われるか、そして不正なネストを避ける方法がわかります。

```text
Card
├── CardHeader
│   ├── CardTitle
│   ├── CardDescription
│   └── CardAction
├── CardContent
└── CardFooter
```

## 追加した理由

**LLM やコーディングエージェントは、完全な構造が見えるときにより正確にコンポーネントを組み立てる**ことがわかりました：ラッパーの欠落が減り、誤ったネスト階層が減り、サンプルとのマッチング精度が向上します。

### ドキュメントをエージェントに持ち込む

あなたまたは LLM は、コンポジション、使い方、サンプルを含む同じコンポーネントドキュメントを CLI からコンテキストとして取得できます：

```bash
npx shadcn@latest docs card
```

[shadcn/skills](/docs/skills) を使用している場合は、これが自動的に行われます。
