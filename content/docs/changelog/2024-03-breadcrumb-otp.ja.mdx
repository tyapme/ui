新しい Breadcrumb コンポーネントと Input OTP コンポーネントを追加しました。

### Breadcrumb

アクセシブルで柔軟なパンくずコンポーネントです。折りたたみアイテム、カスタムセパレーター、独自のルーティング `<Link />` のサポート、および shadcn/ui の他のコンポーネントとの組み合わせが可能です。

<ComponentPreview name="breadcrumb-demo" />

[その他の例を見る](/docs/components/breadcrumb)

### Input OTP

フル機能の OTP 入力コンポーネントです。数字コードと英数字コード、カスタム長、コピー＆ペースト、アクセシビリティをサポートしています。Input OTP は [@guilherme_rodz](https://twitter.com/guilherme_rodz) による [input-otp](https://github.com/guilhermerodz/input-otp) を基盤として構築されています。

<ComponentPreview name="input-otp-demo" />

[ドキュメントを読む](/docs/components/input-otp)

[v0](https://v0.dev) アカウントをお持ちの場合、新しいコンポーネントが生成に利用できます。
