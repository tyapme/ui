title: 2025年7月 - ローカルファイルサポート
description: ローカル JSON ファイルからプロジェクトの初期化とコンポーネントの追加が可能に。
date: 2025-07-07
---

shadcn CLI がローカルファイルをサポートするようになりました。ローカル JSON ファイルからプロジェクトの初期化、コンポーネント、テーマ、hooks、utils などの追加が可能です。

```bash
# ローカルファイルからプロジェクトを初期化
npx shadcn init ./template.json

# ローカルファイルからコンポーネントを追加
npx shadcn add ./block.json
```

この機能により、強力な新しいワークフローが実現します：

- **ゼロセットアップ** - リモートレジストリ不要
- **開発の高速化** - 公開前にレジストリアイテムをローカルでテスト
- **エージェントと MCP のワークフロー強化** - レジストリアイテムをローカルで生成・実行
- **プライベートコンポーネント** - 独自コンポーネントをローカルかつプライベートに保持
