インストール可能なアイテムを提供するオープンソース registry のインデックスを作成しました。

`components.json` ファイルを設定しなくても、registry インデックスからアイテムを検索・閲覧・追加できます。

自動的に `components.json` ファイルへ追加されます。

```bash
npx shadcn add @ai-elements/prompt-input
```

registry の全リストは [https://ui.shadcn.com/r/registries.json](https://ui.shadcn.com/r/registries.json) で確認できます。

registry をインデックスに追加するには、`shadcn/ui` リポジトリに PR を提出してください。詳細は [registry index ドキュメント](/docs/registry/registry-index) を参照してください。
