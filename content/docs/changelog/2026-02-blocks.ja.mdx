すべての [blocks](/blocks) が Radix と Base UI の両方で利用できるようになりました。

- **両ライブラリのすべての blocks** - ログイン、サインアップ、サイドバー、ダッシュボードブロックを含むすべての block が、Radix と Base UI の両方のバリアントで提供されます。
- **同じ CLI ワークフロー** - `npx shadcn add` を実行するだけで、CLI がプロジェクトの設定に基づいて正しい block バリアントを自動選択します。

`npx shadcn create` でプロジェクトをセットアップ済みであれば、blocks は選択したライブラリを自動的に使用します。追加の設定は不要です。

```bash
npx shadcn@latest add login-01
```

[blocks](/blocks) ページでコレクション全体を閲覧できます。
