title: レジストリディレクトリ

---

オープンソースレジストリインデックスは、すぐに使用できるすべてのオープンソースレジストリの一覧です。

`shadcn add` または `shadcn search` を実行すると、CLIは自動的にレジストリインデックスで対象のレジストリを検索し、`components.json` ファイルに追加します。

完全なリストは [https://ui.shadcn.com/r/registries.json](https://ui.shadcn.com/r/registries.json) でご覧いただけます。

公開GitHubレジストリを `owner/repo/item` アドレスで使用するためにレジストリディレクトリに登録する必要はありません。レジストリディレクトリは `@acme` のようなネームスペース向けです。

## レジストリの追加

1. [`apps/v4/registry/directory.json`](https://github.com/shadcn-ui/ui/blob/main/apps/v4/registry/directory.json) にレジストリを追加します
2. `pnpm validate:registries` を実行してレジストリディレクトリを検証します
3. https://github.com/shadcn-ui/ui にプルリクエストを作成します

リクエストを提出すると、チームによって検証・レビューされます。

## 要件

1. レジストリはオープンソースで公開アクセス可能でなければなりません。
2. レジストリは [レジストリスキーマ仕様](/docs/registry/registry-json) に準拠した有効なJSONファイルでなければなりません。
3. レジストリはネストされたアイテムのないフラットなレジストリであることが期待されます。つまり `/registry.json` と `/component-name.json` ファイルはレジストリのルートに置かれる必要があります。
4. `files` 配列が存在する場合、`content` プロパティを含めてはなりません。

有効なレジストリの例を以下に示します:

```json title="registry.json" showLineNumbers
{
  "$schema": "https://ui.shadcn.com/schema/registry.json",
  "name": "acme",
  "homepage": "https://acme.com",
  "items": [
    {
      "name": "login-form",
      "type": "registry:component",
      "title": "Login Form",
      "description": "A login form component.",
      "files": [
        {
          "path": "registry/new-york/auth/login-form.tsx",
          "type": "registry:component"
        }
      ]
    },
    {
      "name": "example-login-form",
      "type": "registry:component",
      "title": "Example Login Form",
      "description": "An example showing how to use the login form component.",
      "files": [
        {
          "path": "registry/new-york/examples/example-login-form.tsx",
          "type": "registry:component"
        }
      ]
    }
  ]
}
```
