# .impeccable.md — ui.tyap.me design context

## Design Context

### Users
Solo developer (yki) building and maintaining a personal UI component library for TYAP.ME products. Secondary audience: other developers who discover and use the library. Japanese-first, technically fluent, opinionated about quality. Context: working environment, code editor open alongside, not a casual browser visit.

### Brand Personality
**precise, personal, quietly opinionated**

Not corporate. Not startup-hustle. The feel of a carefully maintained personal tool — like a well-organized workshop owned by one person who knows exactly where everything is. High standards without performance anxiety.

### Aesthetic Direction
**Existing style — maia — must be respected and extended, not replaced.**

Key characteristics to preserve:
- **Typography**: Geist Sans for both heading and body — clean, neutral, technical. Geist Mono for code. Do not introduce display fonts or decorative type.
- **Radius**: Aggressively rounded — `rounded-4xl` and `rounded-2xl` are the dominant radii. Pill shapes, soft containers. This is the most distinctive visual trait.
- **Color**: OKLCH-based neutral palette. Low chroma, near-achromatic. Accents are rare and purposeful. Both light and dark themes supported equally.
- **Spacing**: Generous. The "maia" style descriptor is "rounded, with generous spacing" — honor that.
- **Motion**: Subtle, functional. Accordion open/close animations are already defined. Follow the existing animation token conventions.
- **Density**: Comfortable — not cramped dashboard density, not marketing-page airiness. Documentation-appropriate.

Anti-references:
- NOT shadcn.com's own aesthetic (even though this is built on shadcn)
- NOT enterprise SaaS (Salesforce, SAP, Atlassian energy)
- NOT AI-generated slop defaults (cyan gradients, glassmorphism, hero metrics)
- NOT "developer tool startup" landing page vibes

### Design Principles
1. **Extend, don't reinvent.** Every new component or page must feel like it was always part of this system.
2. **Rounds and space are load-bearing.** The generous radius and spacing are not decoration — they define the personality. Never tighten or sharpen unless explicitly asked.
3. **Neutral until it matters.** Color carries information, not atmosphere. Reserve accent for state and hierarchy.
4. **Functional first, then refined.** This is a working tool. Clarity outranks cleverness.
5. **Japanese-aware.** Line lengths, spacing, and font rendering should work for both Latin and CJK text.
